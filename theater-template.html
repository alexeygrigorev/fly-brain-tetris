What is calculated, and what is illustrated?

The board follows the trained policy. The default live view feeds the current board plus falling piece into the same full 139,255-neuron linear model. Its six artificial sensory inputs are height, holes, unevenness, horizontal position, descent, and rotation. Activity updates on state changes and every 100 ms of game time, using the latest eight input updates and the model’s impulse response. This added sensory encoding visualizes the changing scene; it was not used to train the placement policy. Switch to Planned move response to see the original trained policy’s candidate-placement inputs across eight recurrent updates. The weights remain fixed in both views. Positions come from the downloaded neuron annotations, shown in an x/z projection. Brightness is normalized per sampled neuron, and values are arbitrary model units—not recorded calcium signals or spikes. The readout evaluates hypothetical placements. The fly's forelegs then illustrate a scripted sequence that executes the chosen rotation, column, and hard drop. Pieces fall independently of this plan. Commands obey walls and stack collisions; a grounded piece locks after 350 ms even if the fly has not finished. Increasing gravity can cause missed placements and game over. We have no body physics, simulated vision, learned limb controller, or biological motor-circuit mapping.
